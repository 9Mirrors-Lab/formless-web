Operator directive · 2026-07-16

Primary wayfinding must be BIG. A full-viewport overlay for the direction map is explicitly welcomed — "we have full real estate, we don't need to be shy." Clarity beats quietness whenever they conflict.

1Design directives — check every page against these

  1. Chrome is a top rail, on every page, always visible. Left: orbit logomark + "Eyes Closed" + mono CLIENT ROOM label. Right: Index · All directions · Exit site ↗. Stage pages add a centered YOU ARE HERE + direction name. Sticky, 44px targets, hairline bottom border.
  2. "All directions" opens a full-viewport overlay — the room's map. Four groups, large serif targets (≥1.5rem mobile / ≥2rem desktop) with intent line + status chip, current direction marked. Close: visible ✕ (44px) + Escape + backdrop click. This replaces the flask forever.
  3. Stages, not dumps. Chrome rail → title block (group eyebrow, serif italic title, intent, status) → work inside a frame. Three frame types only: frame-viewport (browser-chrome plate), frame-plate (matted plate), frame-boards (sequenced plates + switcher).
  4. Multi-board directions live in ONE stage page. Labeled plate-tabs (01 — Vault), ~400ms crossfade inside the same frame, transform+opacity only. No hash navigation, no scroll jump, no per-board files.
  5. Graphic discipline. Science / Icons / Moodboard / Backgrounds may lead with SVG marks and atmosphere. Hero / About / Themes / Foundations stay type-and-space only. Zero decorative filler: if a quiet stage "needs something", it needs nothing.
  6. Motion budget: 2–3 moments per view. Enter reveal chrome → title → content (≤900ms total); index plate stagger; board crossfade. prefers-reduced-motion: everything instant.
  7. Mobile first — 375px is the contract. Rail collapses to mark + label + All directions (the overlay IS mobile nav). No horizontal scroll, no hidden floating buttons.
  8. Semantics. Landmarks, one h1 per page, labeled SVGs, overlay as role="dialog" aria-modal="true" with focus moved on open, returned on close.

3Moves — do · expect · if-instead / because / then

M1Recon the two specimens in a browser (read-only)

Do
Open both specimens in a browser; note board compositions, hero treatments, accents. Read DESIGN.md §2–§11 once. Never read the science HTML as text.
Expect
About shows 4 studies behind its own nav. Science unpacks into 3 dark directions.
Fail
Science stuck on "Unpacking…" or errors → the bundle needs more than file:// grants → take Fork A.

M2Scaffold site/ + build room.css

Do
Create the §2 file map. Define :root tokens from recon (bg, panel, cream, clay, sage, hairlines, three font stacks, --ease). Noise texture only if trivial via inline SVG feTurbulence data-URI; otherwise skip.
Expect
Any stub opened via file:// renders dark cream-on-ink with correct serif.
Fail
Fonts render as Times → fonts link missing or offline → verify link matches the about specimen head; offline is acceptable with fallbacks, note it and continue.

M3Build the shared chrome (rail + overlay) once

Do
Build rail + overlay in index.html per directives 1–2; behavior in room.js (Escape, backdrop, focus move/restore, body scroll lock). Paste into each stage changing only the YOU ARE HERE label, current marker, and ../ prefixes.
Expect
Rail on every page; overlay fills viewport; ✕, Escape and backdrop all close; focus returns to trigger.
Fail
Page scrolls behind overlay → missing scroll lock → toggle .overlay-open on body. Links 404 from stages → root-relative paths survived the paste → audit every href/src in stages/* for the ../ prefix — the single most likely mechanical failure of the mission.

M4Build the index hub

Do
Rail → intro (eyebrow, serif italic h1, 3-sentence how-to: enter → sit with the framed work → return and tell us which feels true) → 4 groups as labeled sections of large entry plates. Framed SVG-sketch thumbs only where a real visual is trivially recreatable (science orbit, icons dots, moodboard field, backgrounds gradient); the rest get calm typographic plates. No fake thumbs.
Expect
1200px: generous editorial grid, scannable across a room. 375px: single column, no horizontal scroll.
Fail
Reads as a dashboard card grid → equal boxes in a uniform grid (banned) → vary scale: In-progress plate full-width, Directions two-up, Foundations/Atmosphere tighter.

M5Stage template + the two single-board quiet stages

Do
hero-templates.html: frame-viewport with a recreated dark hero (eyebrow, two-line serif display, one quiet CTA pill) + a section-rhythm type study. foundations.html: token swatches, type ramp, one motion note with a hover-demo chip. Both stay quiet.
Expect
Curated presentations: chrome, title, framed work, back-link. Nothing full-bleed.
Fail
Hero looks empty → decoration temptation → increase type scale and whitespace instead; quiet stages prove themselves with type and space.

M6The three multi-board stages

Do
About: 4 condensed recreations (Editorial Split, Portrait Hero, Centered Manifesto, Magazine Sidebar), specimen's own nav stripped. Science: Vault / Atelier / Observatory Press, each a dark frame-viewport with its accent key + ONE hero SVG (orbit/field/torus) — the graphic-led showcase. Themes: 3 boards from the --ex-* palettes as mini page-mocks + swatch rows.
Expect
Tabs swap boards with a crossfade inside one persistent frame; chrome never moves; reload lands on board 1.
Fail
Layout jump on switch → unequal board heights → set frame min-height to tallest board. Science boards are guesses (Fork A taken) → label each Interpretive board — from direction notes; do not fake fidelity.

M7Remaining graphic-led stages

Do
Icons: 8–12 line-drawn teaching marks (1.5px strokes, mono captions). Moodboard: Field / Torus / Dissolve as three large plates with serif captions. Backgrounds: three CSS-gradient atmosphere plates in frame-viewports — no animation loops.
Expect
Clearly graphic-led yet framed with chrome intact — with M5 this proves both modes.
Fail
A mark reads as clip-art → filled shapes / detail overload → strokes only, one accent color max.

M8Motion pass

Do
.enter class on DOMContentLoaded drives the 3-step reveal via transition delays; --i stagger on index plates; reduced-motion block zeroes all transitions and makes board swaps instant.
Expect
Chrome → title → content in ≤900ms; with reduced-motion emulated everything is instant.
Fail
Content flashes before reveal → hidden state applied by JS after first paint → put initial hidden state in CSS gated by a .js class added in <head>, so no-JS users still see everything.

M9Mobile pass at 375px

Do
Walk every page at 375px: rail per directive 7, overlay full-screen and scrollable, single-column index, board tabs wrap vertically, 44px targets.
Expect
document.documentElement.scrollWidth === 375 on every page.
Fail
Tab row overflows → serif labels too wide → stack tabs as a 2×2 grid of small plates.

M10Accessibility + link audit

Do
Landmarks, one h1, heading order, real anchors/buttons with visible focus, dialog semantics, labeled SVGs. Then click EVERY link and tab on EVERY page.
Expect
Zero dead links; keyboard-only traversal reaches index → overlay → any stage → boards → exit.
Fail
Switcher not keyboard-operable → tabs built as divs → rebuild as buttons in a role="tablist" with aria-selected.
