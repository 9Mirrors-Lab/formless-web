Publishing — what to bring in-house (save money)

Where the Formless book pipeline can use your time and existing tools instead of vendors, and where outsourcing still pays off.

Related: publishing-roadmap-notes.md, publishing-channels.md, publishing-ingramspark.md.

Rule of thumb: Bring in coordination, portals, metadata, and marketing grunt work in-house. Be careful DIYing edit, interior, and cover on a book that represents the brand. Use author-read audio only if quality bar is met.

What you cannot avoid paying for

These are not “vendor” costs; they are the cost of selling a physical/digital product.

  • Print cost per unit — IngramSpark (or any POD) charges per book printed and shipped; in-house does not remove this.
  • ISBN — Registration fee if you buy your own ISBN (Bowker in the US, or ISBN included in some packages). No real in-house substitute.
  • Proof copies — Physical proofs are worth ordering; budget a few units.
  • Platform cuts — Retailers and audiobook platforms keep a share of list price.
  • Optional ads — Amazon ads, newsletter tools, etc., only if you choose to run them.

Saving money here means fewer formats at launch (e.g. paperback + ebook first, audiobook later), not skipping ISBN or proofs.

Pipeline: in-house vs outsource

1. Manuscript development

In-house Outsource
Self-edit passes, beta readers, your own structural revisions Developmental editor

Save money by: Multiple self-editing rounds, 2–3 trusted readers, clear chapter outline before polish.

Do not skip: A developmental pass if the manuscript still has flow or clarity gaps; fixing structure after typesetting is expensive.

2. Editing

In-house Outsource
Grammar tools (limited), careful read-through, checklist Copy editor, proofreader

Save money by: Copy editor for one pass only; you do pre-clean (remove doubles, standardize terms). Proofread yourself after layout with a printed proof, but a second human proofreader is still safer.

Hybrid: You proof; hire proofreader only for final PDF (cheaper than full developmental + copy + proof stack).

3. Interior formatting / typesetting

In-house Outsource
Vellum, Atticus, Reedsy Book Editor, InDesign (if skilled), Word → PDF (risky) Book designer, typesetter

Save money by: Template tools (Vellum/Atticus) if the book is mostly text. Learn IngramSpark interior size and margin specs once.

Risk: Amateur interior screams self-published; hurts a “quiet, premium” brand.

Hybrid: Template for first edition; pro pass only if reviews mention readability.

4. Cover design

In-house Outsource
Canva (careful), Fiverr mid-tier, AI + human cleanup, your own design skills Cover designer

Save money by: Strong concept yourself; hire only execution (typography, spine, wrap). Use IngramSpark cover template calculator for spine width.

Risk: Cover is the #1 conversion lever on Amazon; weak cover wastes good copy.

5. Metadata + ISBN

In-house Outsource
You write description, pick BISAC/categories, keywords; buy ISBN; own imprint name Metadata specialist

Save money by: Studying comparable titles on Amazon (categories, subtitle patterns, keywords). Reuse website messaging from website-content-arch-guide.md.

Worth outsourcing once if: Launch discoverability matters and you are unsure about Amazon categories.

6. IngramSpark account / title setup

In-house Outsource
You create account, upload PDFs, set prices, enable channels Publishing coordinator

Save money by: Doing all portal steps yourself (see publishing-ingramspark.md). This is mostly clicks and checklist discipline.

Cost if wrong: Rejected files, delayed listing, wrong trim size → re-layout fees in time.

7. File preparation / upload

In-house Outsource
Export print PDF + ebook from your layout tool; validate with IngramSpark preflight Typesetter

Save money by: Exporting both formats from one tool (Vellum/Atticus). Keep one master manuscript.

8. Proof review

In-house Outsource
You review physical proof; mark corrections; re-export Coordinator ships proofs to you

Save money by: Ordering minimum proofs, batching corrections in one revision round.

9. Distribution setup (channels)

In-house Outsource
Toggle retailers in IngramSpark; optional direct KDP; ACX upload yourself Consultant

Save money by: Start with IngramSpark wide + decide Amazon KDP later (publishing-channels.md). Do not pay someone to “get you on Amazon” if you already use IngramSpark.

10. Launch + marketing

In-house Outsource
Email list, Instagram/YouTube you already plan, ARC to friends, formless-web as hub Launch strategist, ads agency

Save money by: Small ARC (20–50 readers), organic posts, link from site. PDF lead magnets from roadmap-website-notes.md double as marketing.

Spend selectively: One short paid consult on Amazon ads beats a full launch package if budget is tight.

11. Ongoing management

In-house Outsource
Check IngramSpark/KDP dashboards occasionally; update bio/links on site Ongoing coordinator

Save money by: Quarterly review only unless a revision edition ships.

Audiobook: in-house savings path

Task In-house option Notes
Narration Author-read Lowest cash cost; highest time cost. Needs quiet room or booth.
Editing audio Descript, Audacity, Reaper Learn noise reduction and ACX loudness specs.
Mastering Freelancer per finished hour Cheaper than full studio package; still often worth it.
ACX upload You Same as IngramSpark: portal work is in-house friendly.

Save money by: Launching audiobook in phase 2 after print/ebook proof the message sells.

Do not: Ship muddy author audio to protect the brand; ACX listeners are unforgiving.

Suggested “lean launch” stack (maximum in-house)

Minimizes vendor spend while keeping quality guardrails.

  1. Manuscript — Self-edit + beta readers; developmental only if stuck.
  2. Edit — One copy edit pass; you pre-clean.
  3. Interior — Vellum or Atticus → print PDF + ebook.
  4. Cover — Mid-tier designer or very strong DIY; never skip spine/wrap check.
  5. ISBN + metadata — You, with Amazon comp research.
  6. Publish — IngramSpark yourself; Amazon strategy per publishing-channels.md.
  7. Proof — One physical proof round.
  8. Launch — Site + YouTube + small ARC; no agency.
  9. Audible — Later; author-read only if audio quality is professional.

Where you still spend money: ISBN, proof copies, one editor and/or one cover, print unit costs, optional ISBN block or ads.

What to keep outsourced (worth the money)

  • Developmental edit — If the book is the product that sells everything else.
  • Cover design execution — If you are not a designer.
  • Copy edit — If the author wrote fast or emotionally (hard to see own patterns).
  • Audiobook mastering — If author-read, before ACX upload.
