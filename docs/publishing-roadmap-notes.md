## Distribution channels (discussing)

| Channel | Formats | Notes |
| --- | --- | --- |
| IngramSpark | Print, ebook | Setup, proofs, wide retail distribution |
| Amazon | Kindle, KDP print | Direct KDP and/or via IngramSpark — TBD |
| Audible | Audiobook | Via ACX; separate narration/production track |
| Substack | Essays, email | Research: excerpts during book dev, subscriber list, post-launch relationship · `substack-approach.html` |
| Other | Ebook, print | Often via IngramSpark (Apple, Kobo, B&N, etc.) |

## Pipeline stages

- Manuscript development
- Editing
- Interior formatting/typesetting
- Cover design
- Metadata + ISBN setup
- IngramSpark account/title setup ([myaccount.ingramspark.com](https://myaccount.ingramspark.com/))
- File preparation/upload
- Proof review
- Distribution setup
- Launch + marketing prep
- Ongoing print/distribution management

core operational setup they require is basically:

- ISBN
- formatted interior PDF
- full wrap cover PDF
- metadata
- pricing/distribution settings
- proof approval
- launch/distribution configuration
