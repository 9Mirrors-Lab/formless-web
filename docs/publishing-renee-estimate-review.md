## Is $11K–$13K reasonable?

Depends what’s inside the black box.

| If the package is… | Ballpark |
| --- | --- |
| Proof only | Often $800–$2,500 (length dependent) |
| Layout only | Often $800–$3,000 |
| Cover only | Often $500–$2,500+ |
| Publishing coordination + all metadata + hand-holding | Often $2,000–$6,000+ |
| **Bundled “done for you” publishing** | **$8,000–$15,000** is common for indie publishers |

So **$11K is not crazy** for proof + layout + cover + guided publish + marketing plan **if** deliverables are clear and revisions are bounded.

It **is expensive** if you’re only getting:

- Light proofread  
- Template layout  
- Stock cover  
- A marketing PDF you won’t execute  

**Your leverage:** You’ve been happy with them; ask to **scope down** what you’ll do yourself and **reprice**, not necessarily leave.
